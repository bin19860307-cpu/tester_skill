# 常见交互模块清单

> Phase 2 需求拆解时，对照此清单自动识别交互模块

## 必查模块（高频交互）

### 1. 用户认证与权限模块
**触发条件**：任何需要登录态的功能

| 交互点 | 测试重点 |
|--------|---------|
| 登录态校验 | 未登录时访问是否跳转登录页 |
| 权限校验 | 无权限时是否正确拦截+提示 |
| 角色隔离 | 不同角色看到的数据/功能是否隔离 |
| Token 过期 | 操作中 Token 失效的处理 |
| 越权操作 | 直接修改请求参数是否能访问他人数据 |

### 2. 操作日志/审计模块
**触发条件**：涉及数据创建、修改、删除的功能

| 交互点 | 测试重点 |
|--------|---------|
| 日志记录 | 关键操作是否写入日志 |
| 日志内容 | 操作人/时间/IP/操作类型是否完整 |
| 日志查询 | 日志能否被正确检索 |
| 操作失败 | 失败操作是否也有日志记录 |

### 3. 消息通知模块
**触发条件**：状态变更、审批流、重要事件

| 交互点 | 测试重点 |
|--------|---------|
| 通知触发 | 特定事件是否触发通知 |
| 通知内容 | 通知内容是否准确（含变量替换） |
| 通知渠道 | 站内信/邮件/短信/企微是否正确发出 |
| 通知对象 | 接收人是否正确（不多发/不漏发） |
| 重复通知 | 同一事件是否会重复发送 |

### 4. 文件存储模块
**触发条件**：涉及文件上传/下载/预览的功能

| 交互点 | 测试重点 |
|--------|---------|
| 上传限制 | 文件格式/大小/数量限制 |
| 上传异常 | 断网/超大文件/异常格式的处理 |
| 存储关联 | 文件删除后关联记录的处理 |
| 权限控制 | 文件是否按权限隔离（不能访问他人文件） |
| CDN/缓存 | 文件更新后是否能访问到新版本 |

### 5. 数据统计/报表模块
**触发条件**：功能操作会产生数据统计变化

| 交互点 | 测试重点 |
|--------|---------|
| 数据同步 | 操作后统计数据是否及时更新 |
| 数据准确性 | 统计结果与明细数据是否一致 |
| 时间范围 | 跨天/跨月的统计边界处理 |
| 删除影响 | 删除数据后统计是否相应减少 |

### 6. 缓存模块
**触发条件**：有列表查询、高频读取的功能

| 交互点 | 测试重点 |
|--------|---------|
| 缓存一致性 | 数据修改后缓存是否刷新 |
| 缓存穿透 | 查询不存在的数据时的处理 |
| 缓存雪崩 | 大量缓存同时失效的处理 |

## 按需检查模块

### 7. 搜索/索引模块
**触发条件**：新增/修改/删除的数据需要被搜索

| 交互点 | 测试重点 |
|--------|---------|
| 索引更新 | 数据变更后搜索结果是否更新 |
| 搜索精度 | 关键词匹配是否准确 |
| 删除同步 | 删除数据后搜索是否消失 |

### 8. 第三方接口
**触发条件**：需要调用外部服务

| 交互点 | 测试重点 |
|--------|---------|
| 接口超时 | 第三方超时时的降级/重试 |
| 返回异常 | 第三方返回错误码的处理 |
| 数据映射 | 第三方数据格式转换是否正确 |

### 9. 工作流/审批模块
**触发条件**：涉及多步骤审批、状态流转

| 交互点 | 测试重点 |
|--------|---------|
| 状态流转 | 所有合法状态转换路径 |
| 非法转换 | 不允许的状态转换是否被拦截 |
| 并发审批 | 同时多人审批同一条记录的处理 |
| 撤回操作 | 撤回后状态和数据的恢复 |

### 10. 导入/导出模块
**触发条件**：功能涉及数据批量导入/导出

| 交互点 | 测试重点 |
|--------|---------|
| 格式校验 | 不符合模板的文件上传处理 |
| 大文件 | 超大文件导入的性能和超时处理 |
| 部分失败 | 批量导入时部分行失败的处理策略 |
| 导出权限 | 只能导出有权限查看的数据 |
