# 流水线状态卡模板

> 每个阶段完成时输出状态卡，确保上下文连贯传递

## 使用说明

每个阶段结束时，生成一张「阶段传递卡」，下一阶段开头引用。
这是保证流水线上下文连贯的关键机制。

---
