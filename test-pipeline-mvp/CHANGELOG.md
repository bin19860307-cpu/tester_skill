# CHANGELOG — test-pipeline-mvp 评测体系（改动-效果对照）

> 每次 Skill 变更（规则/提示词/references/脚本）并在固定基准集全量重跑后，在此追加一条记录。
> 基线冻结条件：**封版前用例不再变动 + 测试人员最终比对确认后**才生成 `baseline/` 快照并写本条。
> 指标定义见 `eval/README.md`：留存率≈有效率、修改率、删除率（分母=首跑生成用例总数）。
>
> 注：本仓库公开版不含内部业务的评测记录与基线快照（`baseline/`、`eval/runs/`、`eval/req-*.md` 已剔除）。
> 以下保留格式模板，供你建立自己的评测基线时参照。
