## 风险等级判定规则

### 基础规则

| 场景 | 风险等级 |
|------|----------|
| 修改认证/权限/支付/数据存储格式模块 | 🔴 高 |
| 修改公共路由/共享工具函数/多处引用的常量 | 🟡 中 |
| 修改单一页面样式/文案/非核心逻辑 | 🟢 低 |
| Revert 操作 | 🟡 中（需验证回滚前后差异） |
| 仅删除无引用的文件 | 🟢 低 |

### 分类风险规则

| 变更类型 | 典型场景 | 风险倾向 |
|---------|---------|---------|
| 变更代码 | 修改已有函数签名/参数 | 🔴 高（调用方可能不兼容） |
| 变更代码 | 修改数据格式/协议字段 | 🔴 高（下游系统可能错位） |
| 变更代码 | 修改条件判断逻辑 | 🟡 中（需覆盖新旧分支） |
| 变更代码 | 修改配置值/阈值 | 🟡 中（需验证影响范围） |
| 新增代码 | 新增函数/文件 | 🟢 低（不影响已有逻辑） |
| 新增代码 | 新增配置项/字段 | 🟢 低（有默认值时风险更低） |
| 新增代码 | 在已有逻辑中新增分支 | 🟡 中（需验证不破坏原有分支） |

### 兼容性评估规则

| 情况 | 兼容性 | 处理建议 |
|------|--------|---------|
| 纯新增字段在末尾追加 | 兼容 | 下游系统按序号取前N个字段不受影响 |
| 新增字段在中间插入 | 不兼容 | 所有后续字段序号后移，下游系统会错位 |
| 修改已有字段格式 | 不兼容 | 下游系统解析会失败 |
| 删除已有字段 | 不兼容 | 下游系统取值会错位 |
| 新增独立文件/函数 | 兼容 | 不影响已有功能 |

## 示例 3：格式 B（结构化 MD）— 依赖包升级（v5.0.0.12 → v5.0.0.13）

**输入格式**：`compare_v5.0.0.13_to_v5.0.0.12.md`（结构化 Markdown 报告）

**格式 B 特征识别**：
- 头部为表格（含「仓库名称」「源版本」「目标版本」「生成时间」「对比范围」字段）
- Commit 清单为带作者/时间的 Markdown 表格
- 每个文件有 `### 📄 filename` 独立标题 + `-N行/+N行` 变更统计
- diff 内容用 ` ```diff ``` ` 代码块包裹

## 两种格式对比速查表

| 对比维度 | 格式 A（tagdiff.txt）| 格式 B（compare_vX_to_Y.md）|
|----------|----------------------|-----------------------------|
| **来源** | Jenkins/CI 流水线 `cat tagdiff.txt` | 结构化 MD 报告工具生成 |
| **头部格式** | `echo` 纯文本行（含仓库地址） | Markdown 表格 |
| **Commit 格式** | `hash message`（无作者/时间） | 表格（含作者/时间） |
| **服务名称** | ✅ 从 `仓库地址:` 提取 URL 末项去 `.git` | ✅ 表格「仓库名称」字段 |
| **文件分隔** | `diff --git a/xxx b/xxx` | `### 📄 filename` 标题 |
| **变更统计** | 无 `-N/+N` 汇总 | 有 `-N行/+N行` 统计 |
| **diff 包裹** | 原始文本，无代码块 | ` ```diff ``` ` 代码块 |
| **信息丰富度** | 标准 | 丰富（多 Commit 作者、时间、规模） |
| **解析难度** | 较低 | 较低（结构更清晰） |
| **适用场景** | CI 流水线直接输出 | 支持结构化报告工具输出 |
